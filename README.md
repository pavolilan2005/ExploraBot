# ExploraBot
ExploraBot_V1 es una placa orientada al control y sensado de un robot explorador autónomo o teleoperado. Su arquitectura central gira en torno a un microcontrolador ESP32, integrando etapas de potencia para motores de corriente directa, acondicionamiento de energía, y una suite completa de sensores para navegación y localización espacial.
